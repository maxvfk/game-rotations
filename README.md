# Game Rotations

Персональная мобильная библиотека игровых ротаций. GitHub Pages: https://maxvfk.github.io/game-rotations/

## Первый MVP (v0.1)

- **Каталог** игр и выбранных команд, поиск, избранное с локальным сохранением.
- **Wuthering Waves**: перенос проверенного интерфейса v1.3 **без потери трёх маршрутов** (1F1A / 2F / 2F Quickswap), схем PC / PS5 / A-H, первой/повторной ротации, портретов, progress и step-by-step. Этот интерфейс временно сохранён как автономный модуль `public/rotations/yyxl-suisui-chisa.html`.
- **Исходные метаданные** игр/команд и provenance в `data/catalog.json`; дальнейшие игры добавляются через единый каталог.
- **Vite + TypeScript**, PWA-кеширование через `vite-plugin-pwa` (включая вложенный HTML и изображения), GitHub Actions build + Pages deploy.

**Важная граница v0.1:** последовательности действий WuWa пока живут в перенесённом автономном модуле. Следующий этап — извлечь их в универсальные, валидируемые JSON-документы, сделать общий renderer с game-specific control maps и затем добавить вторую игру. Не считать это уже завершённой миграцией на общую JSON-схему.

## Разработка

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

В GitHub Settings → Pages установлен **Source: GitHub Actions** (подтверждено владельцем). Workflow проверяет сборку в PR и публикует сайт из `main`. Для повторной публикации можно запустить **Actions → Build and deploy Pages → Run workflow** или отправить новый коммит в `main`. Адрес использует Vite `base: /game-rotations/`.

## Ограничения качества данных

- 1F1A: Prydwen-derived; 2F: адаптация (стык последующих циклов требует проверки); 2F QS: экспериментальная реконструкция, не доказанный TC optimal.
- Не смешивать `verified` сайта-расчётчика, actual live execution и подтверждённый персональный optimal.
- `maxvfk/Games` остаётся canonical research base; в публичном сайте только выбранные памятки и ссылки на источники.
