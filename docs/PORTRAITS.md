# Каталог портретов WuWa — как выбирать изображения для ротаций

**Единый источник соответствий имени, ID и изображения:** [data/portraits/wuthering-waves.json](../data/portraits/wuthering-waves.json). Визуальная проверка на сайте — `?portraits=wuthering-waves` (ссылка «Портреты WuWa» в шапке каталога).

## Откуда данные

Файл пользователя `Wuthering Waves Characters - Builds, Weapons & Echoes.mht`, сохранённая страница Prydwen `/wuthering-waves/characters` от 29.10.2026, в странице указано обновление 22.10.2026. Собрано **61 персонаж/элементный вариант**. Извлечены **61 уникальная связка имени и страницы персонажа**, при этом **58 разных исходных изображений**, поскольку Rover Aero/Electro/Havoc/Spectro используют одинаковый портрет.

**Критическая деталь:** исходные имена CDN неоднозначны (`kakarot_card.webp` — Calcharo, `47_card.webp` — Lucilla, `yang_card.webp` — Yangyang, отдельно `yangyang-xuanling_card.webp`). Никогда не сопоставляй персонажа по basename CDN: связь была получена из **`<a href=.../characters/<slug>>` + `<img alt="name">` той же карточки**. Исходные URL и 12-символьные префиксы SHA-256 сохранены для проверки, что картинка не изменилась.

## Как добавлять команду

1. Найди **точное имя и ID** в `data/portraits/wuthering-waves.json` или в просмотрщике `?portraits=wuthering-waves`.
2. Скопируй `portrait` **без изменений**: `portraits/wuthering-waves/<id>.webp`.
3. Используй этот путь в `data/catalog.json` (`teams[].characters[].portrait`) **и** в `data/rotations/wuthering-waves/<team>.json` (`characters[].portrait`).
4. Для уже существующей команды `YYXL` ID персонажа `yyxl` оставлен совместимым с progress, но путь берётся из алиаса `yyxl → yangyang-xuanling`. **Не путать** `yangyang.webp` и `yangyang-xuanling.webp`.
5. Rover имеет **отдельные ID** `rover-aero`, `rover-electro`, `rover-havoc`, `rover-spectro` (сейчас один оригинальный арт, но 4 записи); в новой ротации выбери именно нужную стихию.
6. Запусти `npm run validate:portraits`, `npm run validate:data`, `npm run build`. Проверка остановит PR, если персонаж WuWa не найден в базе или к нему привязана чужая миниатюра.

## Подготовка изображений и обновления

- Файлы хранятся локально в `public/portraits/wuthering-waves/` и **работают офлайн**. Их не нужно скачивать при каждой сборке или открытии сайта.
- Формат: квадратные WebP **160×160**, верхнеориентированный crop оригинальных карточек 374×512. Исходные полноразмерные карточки в GitHub не сохранялись.
- `scripts/import-wuwa-portraits.mjs` — исторический скрипт импорта, рассчитанный на **строго указанные URL и SHA-префиксы**. Если CDN изменится, он завершится ошибкой вместо тихой подмены картинки. Не запускать регулярно и не считать CDN canonical.
- При новом персонаже: используй подтверждённую карточку (имя, alt, URL страницы, оригинальное изображение), добавь новую запись в registry, миниатюру в `public/portraits/wuthering-waves/`, корректный source и SHA. Проводить ревью именно пары `character ID → лицо` на миниатюре.
- Для корректировки уже существующего портрета сравни исходную страницу и загруженный арт; не меняй ID без миграции URI/прогресса.
- **Авторские права:** фанатский некоммерческий проект; исходные изображения Prydwen, персонажи/игровые изображения Kuro Games. Атрибуция не заменяет лицензию, не удаляй сведения об источнике.

**Что не входит:** собственность на всех персонажей, обновление ростера аккаунта, проверка live-kit/TC или автоматическое обнаружение персонажей. Каталог — snapshot изображений, не мета-источник.
