# Учебные шаблоны (не настоящая игра)

Эти файлы **не попадают на сайт**. Здесь два вымышленных персонажа `alpha` и `beta` из `example-game`; они не являются геймплейными рекомендациями.

- `rotation-template.json` → будущий `data/rotations/<game>/<team>.json`.
- `controls-template.json` → будущий `data/controls/<game>.json`.
- `catalog-team.json` → элемент `teams[]` внутри `data/catalog.json`.

`npm run test:onboarding` пробно добавляет эти данные во временную директорию, создаёт фиктивные placeholder-файлы портретов, запускает production validator, затем проверяет, что несколько ошибок данных отвергаются. В `main` ничего не публикуется.

Реальная команда требует проверенного live-kit, источника, выбранного пользователем варианта, настоящих портретов и игровых биндов, а не только зелёной схемы.
